# Panel interno BRICE

El panel recibe experiencias y reservas desde Supabase Realtime.

- Resumen: actividad en vivo y métricas.
- Reservas: Todas / Hoy / Pendientes funcionan y las reservas reales aparecen.
- Clientes: incorpora clientes provenientes de reservas reales.
- Vehículos: incorpora vehículos provenientes de reservas reales.
- Cotizaciones: muestra las solicitudes provenientes de la experiencia.
